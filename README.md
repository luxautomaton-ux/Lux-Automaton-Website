## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install & Run

```bash
# Clone the repo
git clone https://github.com/luxautomaton-ux/lux-agent-website.git
cd lux-agent-website

# Install dependencies
npm install

# Create environment file
cp .env.example .env.local
# Add your NVIDIA API key to .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### Environment Variables

| Variable | Description |
|----------|-------------|
| `NVIDIA_API_KEY` | NVIDIA API key for LANA chat |
| `NVIDIA_MODEL` | AI model (default: `meta/llama-3.3-70b-instruct`) |
| `CONTACT_EMAIL` | Form submission email |

### Build for Production

```bash
npm run build
npm start
```
