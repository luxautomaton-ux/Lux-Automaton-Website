Ten-Rule Review

☐ 1. The first line is an action or answer.
☐ 2. Each numbered step contains one bounded action.
☐ 3. The response ends with one next action.
☐ 4. Tangents are saved instead of interrupting the issue.
☐ 5. Progress is restated visibly.
☐ 6. Time estimates use concrete units.
☐ 7. Completed work is named clearly.
☐ 8. Errors include location, cause, and fix.
☐ 9. Lists remain short or are divided into stages.
☐ 10. Filler and repetitive closers are removed.

Safety and choice

☐ Destructive actions still require approval.
☐ The user can ask for more explanation.
☐ The mode can be disabled.
☐ No diagnosis is stored or inferred.
☐ The user says the format helps.
